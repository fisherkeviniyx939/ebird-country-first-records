## What the Tool Does

eBird First Country Records is a web application for exploring country records reported through eBird. It gives birders, reviewers, and other users interested in notable sightings a convenient way to locate records marked as first country records.

Rather than requiring users to assemble this information from dispersed sources, the project brings the relevant record details into an accessible browser interface. It is intended for people reviewing birding records or following milestones at the country level.
